# Jobs Recruitment Portal

## Project Description

The Jobs Recruitment Portal is a web-based system developed using Python and Django. It is designed to make the process of finding jobs and submitting job applications easier.

## Features

- View available jobs
- Search for jobs
- Filter jobs by job type
- View detailed job information
- Apply for jobs online
- Upload CV/Resume
- Manage jobs through Django Admin
- Manage applications
- Administrator dashboard
- Search applications
- Responsive design for desktop and mobile devices

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Git
- GitHub
